# Fish Eats Fish (Godot 4)

A minimal 2D prototype where you control a fish and eat smaller fish to grow.

## How to run

1. Open Godot 4.
2. Import this folder (`godot_fish_game`) as a project.
3. Run the project.

## Controls

- Arrow keys: swim in 2D space.

## Rules

- Player starts with `size = 1.0`.
- If the player touches a smaller fish, it is eaten and player size grows.
- If the player touches a bigger fish, it's game over.
